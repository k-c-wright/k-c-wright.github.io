Quản lý bài viết, podcast và sách — không cần viết code.

Cách nhanh nhất: kết nối GitHub một lần (cần một token của bạn). Sau đó chỉ cần chỉnh sửa và bấm Đăng lên website — không phải tải file lên GitHub bằng tay.

Cách dự phòng, không cần token: nhập file content.json, chỉnh sửa, bấm Tải file về rồi tải lên GitHub.

    Mọi thay đổi chỉ nằm trong trình duyệt này cho đến khi bạn bấm Đăng lên website (hoặc Tải file về rồi tự tải lên GitHub). Đóng trang trước đó sẽ làm mất thay đổi.

    Kết nối GitHub

    Làm một lần trên mỗi trình duyệt. Token được lưu chỉ trong trình duyệt này, không gửi đi đâu ngoài GitHub. Không dùng trên máy dùng chung.

    Cách tạo token (khoảng 2 phút)
    1. Đăng nhập GitHub → Settings (ảnh đại diện) → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
    2. Repository access: Only select repositories → chọn repo website của bạn.
    3. Permissions → Repository permissions → Contents: Read and write.
    4. Chọn thời hạn (ví dụ 1 năm) → Generate → sao chép token (bắt đầu bằng github_pat_) và dán vào ô dưới.
